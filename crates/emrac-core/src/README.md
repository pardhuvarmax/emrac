# src/

`lib.rs` is the crate root — it re-exports the public API (`Sources`/`SearchScope`/`SearchResults`, `Plan`/`PlannedPackage`/`PlanAction`, `Error`/`Result`, `Config`, `History`/`TransactionRecord`, `PackageSummary`/`PackageDetails`) and nothing else. `Sources` (in [`sources.rs`](./sources.rs)) is the intended entry point; the source-specific backends in [`backend/`](./backend) aren't re-exported. Data models live in [`package.rs`](./package.rs) and [`plan.rs`](./plan.rs), the crate error type in [`error.rs`](./error.rs), and the persisted TOML config (`~/.config/emrac/config.toml`) in [`config.rs`](./config.rs). Executed transactions are logged by [`history.rs`](./history.rs) to `~/.local/share/emrac/history.jsonl` (append-only JSON Lines). [`rollback.rs`](./rollback.rs) is the pure planning logic for `rollback`/`undo` (inverse of a recorded transaction, post-state check, package-file lookup); `Sources::plan_rollback`/`execute_rollback` wire it to libalpm and pacman.
