# emrac r3-u1

Tag `r3-u1`, 2026-10-16. Version `0.3.1`. Built by pardhuvarmax — https://github.com/pardhuvarmax/emrac

Makepkg's folder variables no longer break the tests, self upgrade cleans its staging folder, self check points at self upgrade, and a release pipeline

Channel: stable

## What changed since `r3`

- release pipeline: a review step (dev/release-review.sh) and an approval gate before publish; prepare --push shows the review and asks
- release pipeline: a tag push starts .github/workflows/release.yml, which checks the tag and runs release.sh publish; prepare gains --channel and --push
- dev/release.sh and docs/design/releasing.md: prepare and publish a small update in two phases, how it is received
- self check: the Updating row points at self upgrade instead of saying emrac cannot update itself
- tests: a guard that the test helper drops makepkg's folder variables
- self upgrade: remove the staging folder even when a build left folders nobody can enter
- tests: the command-line tests ignore PKGDEST, SRCDEST and the other makepkg folders (they leaked in from self upgrade's makepkg and broke check())
- r3 is public: install.sh pinned to it, releases.json entry and news item, project page and changelog

## Updating

`emrac self sync` and then `emrac self upgrade` (or your AUR helper, or pacman with the new package).
Requirements and known limits are those of r3.
