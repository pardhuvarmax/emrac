# plan/r3/

Plans for the slices of release cycle **r3**: the updates made after the `r3` release, numbered
again from `u1`. They go into the next release.

- [`u1-in-place-update.md`](./u1-in-place-update.md) — emrac updates a copy pacman does not own, in place and safely (the pacman path is unchanged).
- [`u2-recommend.md`](./u2-recommend.md) — `emrac recommend`: source or binary, from stated rules; builds are timed from now on. The first of the source-or-binary slices (u2 recommend, u3 explain, u4 score, u5 estimate/eta, u6 benchmark).
- [`u3-explain.md`](./u3-explain.md) — `emrac explain`: the reasoning behind a recommendation, input by input, and what would change it.
